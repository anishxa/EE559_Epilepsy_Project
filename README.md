# EE559 Epilepsy Project

This repository contains the code and data for the EE559 Epileptic Seizure Detection project. 

## Project Overview

The goal of this project is to build machine learning models that can recognize epileptic seizures from data. 

## Files in this Repository

* **EE559_Epilepsy.ipynb**: The main Jupyter Notebook containing the data analysis and models for seizure detection.
* **EE559_Epileptic_Seizure_Baseline.ipynb**: A baseline notebook to compare our models against.
* **Epileptic_Seizure_Recognition.csv**: The dataset used for training and testing the models.

## How to Run

1. Make sure you have Jupyter Notebook or JupyterLab installed.
2. Clone this repository to your local machine.
3. Open either of the `.ipynb` notebooks to view the code and run the cells.
